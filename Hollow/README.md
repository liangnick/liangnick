# 文本输入记录工具

这是一个简单的文本输入记录工具，可以帮助您快速记录文本内容并保存到文件中。

## 功能特性

- ✅ 简洁的GUI界面，支持多行文本输入
- ✅ 自动保存到以日期命名的TXT文件
- ✅ 提供保存按钮和快捷键支持（Ctrl+Enter）
- ✅ 实时状态提示
- ✅ 支持窗口大小调整
- ✅ 美观的现代化界面设计

## 如何使用

### 方法一：直接运行Python脚本

1. 确保您的系统已经安装了Python 3.x
2. 打开命令行窗口，进入项目目录
3. 运行命令：`python code\text_recorder.py`
4. 在弹出的窗口中输入文本
5. 点击"确认保存"按钮或按下Ctrl+Enter保存文本

### 方法二：使用批处理文件（Windows）

1. 确保您的系统已经安装了Python 3.x
2. 双击`run_text_recorder.bat`文件
3. 在弹出的窗口中输入文本
4. 点击"确认保存"按钮或按下Ctrl+Enter保存文本

## 项目结构

```
项目根目录/
├── code/                    # 代码文件目录
│   ├── text_recorder.py     # 主程序文件
│   └── run_hidden.vbs       # 隐藏窗口脚本
├── logs/                    # 日志和测试文件目录
│   ├── BUTTON_FIX_REPORT.md # 按钮修复报告
│   ├── HIDDEN_WINDOW_REPORT.md # 隐藏窗口功能报告
│   └── TEST_RESULT.md       # 测试结果报告
├── output/                  # 输出文件目录
│   └── YYYYMMDD.txt         # 生成的文本文件（以日期命名）
├── run_text_recorder.bat    # Windows批处理启动文件
└── README.md                # 项目说明文档
```

## 技术特点

- 使用Python的tkinter库构建GUI界面
- 采用了现代化的设计风格
- 支持快捷键操作，提高效率
- 自动处理文件路径和日期命名
- 提供实时状态反馈
- 隐藏命令行窗口，提供更整洁的用户体验

## 界面设计

- 主色调：蓝色（#2561EF）
- 背景色：白色（#FAFAF2）
- 文本颜色：深灰色（#333333）
- 字体：系统默认字体，字号适中

## 保存说明

- 文本会自动保存到`output`目录下以当前日期命名的TXT文件中
- 文件名格式：YYYYMMDD.txt（例如：20251208.txt）
- 每次保存会在文件中添加时间戳

## 快捷键

- `Ctrl+Enter` - 保存文本

## 系统要求

- Python 3.x
- Windows/Linux/MacOS系统

## 注意事项

- 确保您有足够的权限在当前目录下创建和写入文件
- 如果保存失败，请检查文件权限和磁盘空间
- 如果界面显示异常，请检查您的系统是否支持tkinter库
- 如果程序无法启动，请检查Python是否已正确安装并添加到系统PATH中
