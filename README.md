# liangnick 的开源作品集

这里是我的个人开源项目集合，每个项目都是独立维护的。

## 🗂️ 项目列表

### [Hollow](https://github.com/liangnick/hollow) · 树洞 PC 客户端

只能自己跟树洞说的话，就写在这里。一个极简的本地记录工具，帮你保存那些无法对人分享的内心独白。

- **技术栈**：Python + Tkinter
- **功能**：私密文本记录 / 自动按日期保存 / 隐藏窗口运行
- **仓库**：[github.com/liangnick/hollow](https://github.com/liangnick/hollow)

---

### [Moment](https://github.com/liangnick/moment) · 手机照片视频备份工具

把手机里珍贵的照片和视频轻松备份到电脑，按日期整理，不再丢失任何一个瞬间。

- **技术栈**：Python
- **功能**：一键导入 / 自动按日期分类 / 去重
- **仓库**：[github.com/liangnick/moment](https://github.com/liangnick/moment)

---

### [AAdazi](https://github.com/liangnick/aadaizi) · 搭子 AA 记账

旅游、吃饭、演唱会、拼单……和搭子一起消费，AA 分账从此不再纠结。每人花了多少、谁欠谁多少，一眼看清。

- **技术栈**：待定
- **功能**：多成员分账 / 自动清算 / 账单历史
- **仓库**：[github.com/liangnick/aadaizi](https://github.com/liangnick/aadaizi)
