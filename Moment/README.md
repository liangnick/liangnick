# 照片/视频整理工具

一个基于Python开发的照片和视频整理工具，支持按日期自动分类和归档媒体文件。

## 功能特性

- 📁 **自动分类**：根据文件名中的日期信息自动将照片和视频分类到对应的年份和月份文件夹
- 🎥 **视频支持**：单独设置视频备份目录，支持将视频文件按年份分类
- 🎨 **友好界面**：使用Tkinter开发的简洁直观的图形用户界面
- ⚡ **高效处理**：支持批量处理大量文件，并显示处理进度
- 📊 **结果统计**：提供详细的处理结果统计信息
- 🔄 **冲突处理**：智能处理文件重名冲突，确保文件安全

## 技术栈

- **Python 3.10+**：项目开发语言
- **Tkinter**：图形用户界面开发
- **PyInstaller**：可执行文件打包

## 使用方法

### 直接运行（推荐）

1. 下载或找到项目根目录下的 `photo_organizer.exe` 文件
2. 双击运行该可执行文件
3. 按照界面提示操作：
   - 选择原始照片/视频目录
   - 选择照片备份目录
   - 选择视频备份目录（可选）
   - 点击「开始整理」按钮

### 从源代码运行

1. 确保已安装 Python 3.10 或更高版本
2. 打开命令行终端，进入项目的 src 目录
3. 运行以下命令：
   ```bash
   python photo_organizer.py
   ```

## 构建可执行文件

如果您想自己构建可执行文件：

1. 确保已安装 PyInstaller：
   ```bash
   pip install pyinstaller
   ```

2. 进入 src 目录，运行以下命令：
   ```bash
   pyinstaller --onefile --windowed photo_organizer.py
   ```

3. 构建完成后，可执行文件将生成在 `dist` 目录中

## 工作原理

1. **文件扫描**：程序会扫描您指定的原始目录，识别照片和视频文件
2. **日期解析**：从文件名中提取日期信息（格式：`_YYYYMMDD_`）
3. **目录创建**：根据提取的日期创建对应的年份和月份文件夹
4. **文件移动**：将文件移动到相应的目标文件夹
   - 标准格式文件：按年份/月份分类
   - 非标准格式文件：放入 `temp` 文件夹
5. **冲突处理**：
   - 文件大小相同：直接覆盖
   - 文件大小不同：重命名新文件（添加序号）

## 文件命名规则

程序支持以下格式的文件名解析：
- 照片：`*_YYYYMMDD_*.jpg`（或其他照片格式）
- 视频：`*_YYYYMMDD_*.mp4`（或其他视频格式）

例如：
- `IMG_20231225_153045.jpg` → 2023年12月
- `VID_20240101_120000.mp4` → 2024年1月

## 支持的文件格式

### 照片

- .raw

### 视频

- .mov
- .avi

- .wmv
- .flv
- .webm
- .mpg / .mpeg

## 注意事项

1. 原始目录和备份目录不能相同
2. 请至少选择一个备份目录（照片或视频）
3. 处理大量文件时可能需要一些时间，请耐心等待
4. 建议在处理前备份重要文件
